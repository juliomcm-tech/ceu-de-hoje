Eliminar os teus dados

App «Céu de Hoje» · ceudehoje.com · Júlio Melo

Resumo: o Céu de Hoje não tem contas nem registo. Quase tudo fica só no teu telemóvel. O único dado guardado no nosso servidor é o endereço técnico dos avisos (notificações), e só se os ligares.

1. Apagar os avisos do servidor

Se ligaste os avisos (notificações), o servidor guarda o endereço técnico do teu telemóvel, um código aleatório, as horas que escolheste e o fuso horário. Para os apagar:

  • Abre a app → ⚙ Definições → ⏰ Avisos à hora certa → desliga os avisos.

São apagados de imediato do servidor. Se o endereço deixar de funcionar (por exemplo, desinstalaste a app), é apagado automaticamente no envio seguinte.

2. Apagar os dados do telemóvel

Perfil, Carta da Alma e ligações, aniversários, animais, diário, ciclo, livros, viagens, fotos e definições ficam só no teu telemóvel. Nós nunca os recebemos. Para os apagar, escolhe uma opção:

  • Desinstalar a app (ou, no navegador, apagar os dados do site ceudehoje.com).
  • Nas definições do Android: Apps → Céu de Hoje → Armazenamento → Limpar dados.
  • Se usas PIN no diário: no ecrã do PIN, «Esqueci o PIN» apaga todos os dados pessoais deste telemóvel.

As cópias de segurança que tu próprio guardaste (ficheiros) ficam onde as puseste: apaga-as tu.

3. Pesquisas

As pesquisas de livros e séries vão diretamente para o Google Books, a Open Library e o TVMaze para mostrar os resultados. Nós não as guardamos.

4. Pedir por email

Se preferires, escreve para contacto@ceudehoje.com com o assunto «Eliminar dados». Apagamos o que existir no servidor no prazo de 30 dias. Como não há contas, não guardamos mais nada sobre ti.
